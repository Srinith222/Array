# Array

A simple Python project demonstrating how to build and use an array-like data structure.

## Features
- Append values
- Insert at a position
- Remove values
- Search for an item
- Sort and reverse
- Display array contents

## Run
```bash
python array.py
```

## Example
```python
arr = Array()
arr.append(10)
arr.append(20)
arr.append(30)

print(arr)      # [10, 20, 30]
print(arr.size())
print(arr.search(20))
```
